Proyectos

El código ya está ahí. El contexto hay que encontrarlo.

Así aborda mini-consumes-tokens la consulta de código desde herramientas de IA.

Proyecto destacado

mini-consumes-tokens

Un servidor MCP que ayuda a las herramientas de IA a consultar código con menos contexto. Indexa el repositorio localmente y permite localizar símbolos, referencias y relaciones entre funciones sin releer archivos completos.

  • Rust
  • MCP
  • SQLite
  • Tree-sitter
Ver código y documentación↗
  1. 01

    Volver a leer el mismo código

    Para encontrar una función o saber dónde se usa, un asistente de IA puede acabar leyendo archivos completos una y otra vez. Esa lectura ocupa parte de su contexto disponible.

  2. 02

    Crear un índice local

    mini-consumes-tokens analiza el código con Tree-sitter y guarda símbolos y relaciones en SQLite. El servidor MCP y la CLI permiten consultar ese índice en el propio equipo.

  3. 03

    Acceder al contexto relevante

    Las consultas localizan definiciones, referencias y llamadas. Los paquetes de contexto reúnen información sobre un símbolo para que el asistente pueda centrarse en el código que necesita.
