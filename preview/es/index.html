Proyecto destacado

mini-consumes-tokens

Código que ayuda a consultar código.

Un servidor MCP que ayuda a las herramientas de IA a consultar código con menos contexto. Indexa el repositorio localmente y permite localizar símbolos, referencias y relaciones entre funciones sin releer archivos completos.

Ver código y documentación↗

Contexto centrado en lo que necesitas

Cuando un asistente consulta un repositorio, puede acabar leyendo archivos completos una y otra vez. Este proyecto crea un índice local para localizar las partes relevantes del código.

  1. Indexar el repositorio local
  2. Localizar símbolos y relaciones
  3. Consultar contexto específico

Tecnologías del proyecto

  • Rust
  • MCP
  • SQLite
  • Tree-sitter
