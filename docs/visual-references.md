## Proposed Starting Direction

Combine readable professional content with one technical interaction rooted in `mini-consumes-tokens`: for example, an accessible comparison between a full file and a focused symbol context. This is a proposal, not an approved design. Any example must be labeled as illustrative unless measured against real project data.

Borrow principles, not layouts, assets, branding, or biography. Keep the featured project easy to reach on mobile, with keyboard access and reduced motion. Immersive 3D or desktop navigation requires extra performance and usability work; it is optional.

## Owner Review

The owner selected Tamal Sen and Henry Heffernan as the preferred references. The remaining references did not resonate. Clarify the appealing details (structure, typography, colors, motion, or interaction), then record a specific concept in `design-brief.md` before building the final interface.
